# IPARR issues and ideas

This is the public place to report problems with IPARR and to suggest new features or sources. The IPARR code itself is not published here.

**Use IPARR**

- Website: https://iparr.amirulandalib.eu.org
- Telegram bot: https://t.me/IPArrBOT
- Merged repo for your signer: `https://iparr.amirulandalib.eu.org/repo.json`
  - Lite (newest 1,000 apps): `https://iparr.amirulandalib.eu.org/repo.lite.json`
  - AltStore / SideStore (one entry per bundle ID): `https://iparr.amirulandalib.eu.org/repo.altstore.json`

**Get help or give feedback**

- [Report a bug](https://github.com/AmirulAndalib/iparr-issues/issues/new?template=bug_report.yml): something on the website, in the bot or in a repo feed doesn't work.
- [Request a source](https://github.com/AmirulAndalib/iparr-issues/issues/new?template=source_request.yml): an IPA repo that IPARR should watch.
- [Suggest a feature](https://github.com/AmirulAndalib/iparr-issues/discussions/new?category=ideas): ideas and improvements go to Discussions, so others can vote on them.
- [Ask a question](https://github.com/AmirulAndalib/iparr-issues/discussions/new?category=q-a).

Before opening an issue, search the existing ones. If the problem is with a single app build (it crashes, it's fake, the link is dead), that usually belongs to the source that published it. IPARR only lists links that sources publish and does not host IPA files.

Only IPA repos are in scope. Jailbreak `.deb` repos are not added.

Please don't post personal data, tokens or private links in public issues.
